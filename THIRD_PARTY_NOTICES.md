## Lineage & Original Projects

1. **PDFMathTranslate-next**
   - **Repository:** [https://github.com/PDFMathTranslate/PDFMathTranslate-next](https://github.com/PDFMathTranslate/PDFMathTranslate-next)
   - **Inspiration:** The core concept and architectural inspiration were discovered through Chip Huyen's curated *GoodAIList*.
   - **License:** GNU Affero General Public License v3.0 (AGPL-3.0).

2. **VI-Translate**
   - **Repository:** [https://github.com/breslee1707/VI-Translate](https://github.com/breslee1707/VI-Translate)
   - **Author:** `breslee1707`
   - **Inspiration:** Discovered on Facebook community discussions. Served as the direct foundation for Vietnamese document translation enhancements and GUI tooling.
   - **License:** GNU Affero General Public License v3.0 (AGPL-3.0).

3. **PDFMathTranslate (Core `pdf2zh/`)**
   - **Repository:** [https://github.com/PDFMathTranslate/PDFMathTranslate](https://github.com/PDFMathTranslate/PDFMathTranslate)
   - **Version:** 1.9.11
   - **Notice:** The `pdf2zh/` directory is a preservation-focused core derived from PDFMathTranslate. It retains PDF parsing, formula and math placeholder handling, layout detection, typography rendering, and translation cache facilities.
   - **License:** GNU Affero General Public License v3.0 (AGPL-3.0).

4. **BabelDOC**
   - **Repository:** [https://github.com/funstory-ai/BabelDOC](https://github.com/funstory-ai/BabelDOC)
   - **Version:** 0.2.33
   - **Notice:** Used for pinned layout-analysis model (`doclayout.onnx`) and multilingual font assets (`GoNotoKurrent-Regular.ttf`).
   - **License:** GNU Affero General Public License v3.0 (AGPL-3.0).

5. **External Services**
   - Document translation in default GUI mode uses Google Translate's public web service. Google does not sponsor, endorse, or manage this software. Usage is subject to Google's Terms of Service.
   - Optional LLM translation gateways (OpenAI, Google Gemini, Anthropic Claude, Ollama, 9router) operate via user-provided API credentials.
